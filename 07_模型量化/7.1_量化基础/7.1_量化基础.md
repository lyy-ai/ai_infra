# 7.1 量化基础

## 1. 量化本质：用更少比特位表示权重/激活

### 核心思想

模型量化（Quantization）是将神经网络中的 **权重（Weights）** 和 **激活（Activations）** 从高精度的浮点数（通常是 FP32）映射到低精度整数（如 INT8、INT4、INT2 等）的过程。

> 本质：在**可接受的精度损失范围内**，用更少的比特位表示张量，从而减少模型体积、降低内存带宽、加速推理计算。

### 为什么需要量化？

| 收益维度             | 说明                                                       |
| -------------------- | ---------------------------------------------------------- |
| **模型体积↓** | INT8 相比 FP32 体积减少约 4 倍；INT4 减少约 8 倍           |
| **内存带宽↓** | 读取更小的权重，减少访存压力                               |
| **推理延迟↓** | 整数运算比浮点运算更快，且适合专用硬件（NPU/TPU/INT8 DSP） |
| **能耗↓**     | 低比特运算单元面积更小、功耗更低                           |

### 线性量化公式推导

给定浮点张量 $x$，要映射到 $b$ 位整数：

**前向量化：**

$$
x_q = \text{clip}\left(\text{round}\left(\frac{x}{s}\right) + z,\, q_{\min},\, q_{\max}\right)
$$

**反量化：**

$$
\hat{x} = s \cdot (x_q - z)
$$

其中：

- $q_{\min} = -2^{b-1}$, $q_{\max} = 2^{b-1}-1$（有符号）
- $s$：缩放因子（scale）
- $z$：零点（zero point）
- $x_q$：量化后的整数值

#### Scale 与 Zero Point 推导

##### 对称量化

假设 $x \in [-\alpha, \alpha]$，且 $z = 0$：

$$
s = \frac{\alpha}{2^{b-1} - 1}
$$

量化：

$$
x_q = \text{round}\left(\frac{x}{s}\right)
$$

##### 非对称量化

假设 $x \in [x_{\min}, x_{\max}]$：

$$
s = \frac{x_{\max} - x_{\min}}{q_{\max} - q_{\min}} = \frac{x_{\max} - x_{\min}}{2^b - 1}
$$

$$
z = q_{\min} - \text{round}\left(\frac{x_{\min}}{s}\right)
$$

> 常用变体：$z = \text{round}\left(-\frac{x_{\min}}{s}\right)$，对应 $[0, 2^b-1]$ 无符号量化。

## 2. 对称量化 vs 非对称量化

### 对称量化（Symmetric Quantization）

假设数据分布关于 0 对称，零点固定为 0：

$$
x_q = \text{round}\left(\frac{x}{s}\right), \quad x_q \in [-2^{b-1}, 2^{b-1}-1]
$$

**特点：**

- zero point $z = 0$
- 计算简单，适合 **权重（Weights）**
- 硬件实现友好，省掉 zero-point 加法
- 对 ReLU 等全正激活会有精度损失

### 非对称量化（Asymmetric Quantization）

不假设对称分布，使用 min/max 确定 scale 和 zero point：

$$
s = \frac{x_{\max} - x_{\min}}{2^b - 1}, \quad z = \text{round}\left(-\frac{x_{\min}}{s}\right)
$$

**特点：**

- zero point $z \neq 0$
- 更适合 **激活（Activations）**，尤其是 ReLU 输出全为正的情况
- 计算稍复杂，推理时需额外处理 zero point

### 对比总结

| 维度       | 对称量化             | 非对称量化                 |
| ---------- | -------------------- | -------------------------- |
| zero point | 0                    | 可非 0                     |
| 适用数据   | 近似零均值、对称分布 | 非对称分布（如 ReLU 激活） |
| 硬件开销   | 低                   | 略高                       |
| 典型应用   | 权重（Weights）      | 激活（Activations）        |
| 精度       | 对全正数据稍差       | 更灵活，精度通常更好       |

### 代码示例：`symmetric_vs_asymmetric.py`

```python
# symmetric_vs_asymmetric.py
import torch
import numpy as np


def symmetric_quantize(x, bits=8):
    """对称量化"""
    alpha = torch.max(torch.abs(x.min()), torch.abs(x.max()))
    qmax = 2 ** (bits - 1) - 1
    scale = alpha / qmax
    x_q = torch.round(x / scale).clamp(-qmax - 1, qmax)
    x_deq = x_q * scale
    return x_q, x_deq, scale, 0


def asymmetric_quantize(x, bits=8):
    """非对称量化"""
    x_min, x_max = x.min(), x.max()
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    scale = (x_max - x_min) / (qmax - qmin)
    zero_point = qmin - torch.round(x_min / scale)
    zero_point = torch.clamp(zero_point, qmin, qmax)
    x_q = torch.round(x / scale + zero_point).clamp(qmin, qmax)
    x_deq = scale * (x_q - zero_point)
    return x_q, x_deq, scale, zero_point


if __name__ == "__main__":
    torch.manual_seed(42)
    x = torch.randn(10) * 3  # 假设激活值

    print("原始张量:", x)
    print()

    sq, s_deq, s_scale, _ = symmetric_quantize(x)
    print("对称量化:")
    print("  scale:", s_scale.item())
    print("  量化值:", sq)
    print("  反量化:", s_deq)
    print(f"  MSE: {torch.mean((x - s_deq) ** 2).item():.6f}")
    print()

    aq, a_deq, a_scale, a_zp = asymmetric_quantize(x)
    print("非对称量化:")
    print("  scale:", a_scale.item())
    print("  zero_point:", a_zp.item())
    print("  量化值:", aq)
    print("  反量化:", a_deq)
    print(f"  MSE: {torch.mean((x - a_deq) ** 2).item():.6f}")
```

## 3. Per-tensor vs Per-channel 量化

### Per-tensor 量化（张量级）

整个张量共享 **一个 scale 和一个 zero point**。

- 优点：实现简单、硬件友好、计算开销小
- 缺点：对通道间数值范围差异大的层（如卷积通道）精度损失较大

### Per-channel 量化（通道级）

每个输出通道使用独立的 scale 和 zero point。

- 优点：精度更高，尤其适合卷积权重
- 缺点：硬件实现复杂，需要更多存储和计算资源

### 扩展：其他粒度

| 粒度                             | 说明                     | 典型应用                           |
| -------------------------------- | ------------------------ | ---------------------------------- |
| **Per-tensor**             | 整个张量一个 scale       | 激活、部分权重                     |
| **Per-channel**            | 每个通道一个 scale       | 卷积权重                           |
| **Per-token**              | 每个 token 一个 scale    | LLM 激活（如 SmoothQuant）         |
| **Per-group / Block-wise** | 每$g$ 个元素一个 scale | INT4/INT3 LLM 权重（如 GPTQ、AWQ） |

### 选择建议

- **移动端/边缘端**：优先 Per-tensor，硬件友好
- **服务器 GPU/NPU**：可使用 Per-channel 或 Per-group 提升精度
- **大语言模型（LLM）**：当前主流是 Per-channel 权重 + Per-token 激活，或 Group-wise 量化

### 代码示例：`per_tensor_vs_per_channel.py`

```python
# per_tensor_vs_per_channel.py
import torch


def per_tensor_quantize(w, bits=8):
    w_min, w_max = w.min(), w.max()
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    scale = (w_max - w_min) / (qmax - qmin)
    zp = qmin - torch.round(w_min / scale)
    zp = torch.clamp(zp, qmin, qmax)
    w_q = torch.round(w / scale + zp).clamp(qmin, qmax)
    return scale * (w_q - zp)


def per_channel_quantize(w, bits=8):
    # w shape: [out_channels, in_channels]
    out_c = w.shape[0]
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    w_deq = torch.zeros_like(w)

    for c in range(out_c):
        wc = w[c]
        w_min, w_max = wc.min(), wc.max()
        scale = (w_max - w_min) / (qmax - qmin)
        zp = qmin - torch.round(w_min / scale)
        zp = torch.clamp(zp, qmin, qmax)
        w_q = torch.round(wc / scale + zp).clamp(qmin, qmax)
        w_deq[c] = scale * (w_q - zp)

    return w_deq


if __name__ == "__main__":
    torch.manual_seed(0)
    # 模拟卷积权重，8 个输出通道
    w = torch.randn(8, 16)
    # 让每个通道尺度差异大
    for c in range(8):
        w[c] *= (c + 1) * 0.5

    w_pt = per_tensor_quantize(w)
    w_pc = per_channel_quantize(w)

    mse_pt = torch.mean((w - w_pt) ** 2).item()
    mse_pc = torch.mean((w - w_pc) ** 2).item()

    print(f"Per-tensor MSE: {mse_pt:.6f}")
    print(f"Per-channel MSE: {mse_pc:.6f}")
```

> 当通道间数值范围差异大时，Per-channel MSE 通常明显小于 Per-tensor。

## 4. 量化误差分析与校准算法

### 量化误差来源

| 误差类型                             | 来源                                 |
| ------------------------------------ | ------------------------------------ |
| **截断误差（Clipping Error）** | 超出量化范围的值被截断到 min/max     |
| **舍入误差（Rounding Error）** | 浮点映射到整数时的 round 损失        |
| **粒度误差**                   | Per-tensor 无法刻画通道/token 间差异 |
| **动态范围估计误差**           | 校准数据不能代表真实分布             |

### 误差度量

常用指标：

- **MSE（Mean Squared Error）**：$\min_s \mathbb{E}[(x - \hat{x})^2]$
- **SNR / SQNR（Signal-to-Quantization-Noise Ratio）**
- **Top-1 / Top-5 精度下降**：端到端任务指标

### 校准算法（Calibration）

用于确定最佳的 scale 和 zero point。常用策略：

| 算法                         | 思想                               | 特点                        |
| ---------------------------- | ---------------------------------- | --------------------------- |
| **Min-Max**            | 用校准集的最小/最大值定范围        | 简单直接，但对异常值敏感    |
| **Percentile**         | 用百分位数（如 99.9%）定范围       | 抑制异常值，适合激活        |
| **Entropy（KL 散度）** | 最小化原始分布与量化分布的 KL 散度 | TensorRT 默认方法，精度较好 |
| **MSE 优化**           | 最小化量化前后的均方误差           | 精度高，计算成本略大        |
| **网格搜索 / 自适应**  | 在候选 scale 中搜索最优值          | 如 AdaRound、BRECQ          |

### 代码示例：`calibration_methods.py`

```python
# calibration_methods.py
import torch
import numpy as np


def minmax_calibration(x, bits=8):
    return x.min(), x.max()


def percentile_calibration(x, bits=8, percentile=99.99):
    lower = torch.quantile(x, (100 - percentile) / 100)
    upper = torch.quantile(x, percentile / 100)
    return lower, upper


def mse_calibration(x, bits=8, num_candidates=100):
    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    abs_max = torch.abs(x).max()
    best_mse = float("inf")
    best_scale = None

    for ratio in torch.linspace(0.5, 1.0, num_candidates):
        alpha = abs_max * ratio
        scale = alpha / qmax
        x_q = torch.round(x / scale).clamp(-qmax - 1, qmax)
        x_deq = x_q * scale
        mse = torch.mean((x - x_deq) ** 2)
        if mse < best_mse:
            best_mse = mse
            best_scale = scale

    alpha = best_scale * qmax
    return -alpha, alpha


def kl_calibration(x, bits=8, num_bins=2048):
    """
    简化的 KL 散度校准，参考 TensorRT 思想
    """
    x_np = x.detach().cpu().numpy()
    abs_max = np.abs(x_np).max()
    hist, bin_edges = np.histogram(
        np.clip(x_np, -abs_max, abs_max),
        bins=num_bins,
        range=(-abs_max, abs_max),
    )

    qmin, qmax = -(2 ** (bits - 1)), 2 ** (bits - 1) - 1
    best_kl = float("inf")
    best_threshold = abs_max

    for i in range(1, num_bins):
        threshold = bin_edges[i]
        # 原始分布
        P = np.concatenate([hist[:i], [np.sum(hist[i:])]])
        # 量化后分布
        bins_per_int = i / qmax
        Q = np.zeros_like(P)
        for j in range(len(P)):
            q_idx = int(j / bins_per_int)
            q_idx = min(q_idx, qmax)
            Q[q_idx] += P[j]

        # 避免 log(0)
        P = P / (P.sum() + 1e-10)
        Q = Q / (Q.sum() + 1e-10)
        kl = np.sum(P * np.log((P + 1e-10) / (Q + 1e-10)))
        if kl < best_kl:
            best_kl = kl
            best_threshold = threshold

    return -best_threshold, best_threshold


if __name__ == "__main__":
    torch.manual_seed(42)
    # 模拟带异常值的激活
    x = torch.randn(10000)
    x[0] = 20.0  # 异常值

    methods = {
        "Min-Max": minmax_calibration,
        "Percentile": percentile_calibration,
        "MSE": mse_calibration,
        "KL": kl_calibration,
    }

    for name, fn in methods.items():
        xmin, xmax = fn(x)
        scale = (xmax - xmin) / 255
        x_q = torch.round((x - xmin) / scale).clamp(-128, 127)
        x_deq = x_q * scale + xmin
        mse = torch.mean((x - x_deq) ** 2).item()
        print(f"{name:12s}: range=[{xmin:7.3f}, {xmax:7.3f}], MSE={mse:.6f}")
```

> 含异常值时，Percentile / MSE / KL 通常比 Min-Max 更鲁棒。

## 5. PyTorch 内置 PTQ 示例

```python
# pytorch_ptq_demo.py
import torch
import torch.quantization
from torchvision import models


def demo_pytorch_ptq():
    model = models.resnet18(weights=None)
    model.eval()

    # 1. 设置 qconfig
    model.qconfig = torch.quantization.get_default_qconfig("fbgemm")

    # 2. 准备模型
    model_prepared = torch.quantization.prepare(model)

    # 3. 用校准数据前向（收集统计信息）
    with torch.no_grad():
        for _ in range(10):
            dummy = torch.randn(1, 3, 224, 224)
            model_prepared(dummy)

    # 4. 转换
    model_quantized = torch.quantization.convert(model_prepared)

    print(model_quantized)
    print("\n量化完成，可用 torch.jit.save 导出。")


if __name__ == "__main__":
    demo_pytorch_ptq()
```

> 注意：PyTorch 静态量化主要在 CPU 后端生效，需要 `fbgemm`（x86）或 `qnnpack`（ARM）后端。

## 6. PTQ vs QAT

| 方法          | 全称                        | 说明                                       |
| ------------- | --------------------------- | ------------------------------------------ |
| **PTQ** | Post-Training Quantization  | 训练后直接量化，无需重新训练，速度快       |
| **QAT** | Quantization-Aware Training | 训练时模拟量化误差，精度更高，但训练成本高 |

> 实践建议：优先尝试 PTQ + 好的校准算法；若精度不满足，再用 QAT 微调。

---

## 7. 本节小结

1. 量化是用低比特整数近似浮点张量，目标是 **降体积、省带宽、加速、低功耗**
2. **对称量化** 适合权重，**非对称量化** 适合激活
3. **Per-tensor** 硬件友好，**Per-channel/Per-group** 精度更高
4. 量化误差不可避免，需通过 **校准算法** 和 **PTQ/QAT** 策略进行优化
