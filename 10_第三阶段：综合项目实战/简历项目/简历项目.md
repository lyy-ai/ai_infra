# 简历项目：综合项目实战

## 项目：自动驾驶 MMBEV 模型端到端多平台部署优化

### 一句话描述

负责自动驾驶 MMBEV 模型在 Orin / A100 / Ascend 三平台的端到端部署优化，端到端延迟降低 70%、吞吐提升 3 倍、通过量产验证。

### 简历写法

> **自动驾驶 MMBEV 模型端到端多平台部署优化**
> - **HPC 算子开发**：负责 MMBEV 核心算子（BEV Pooling、Deformable Attention、LayerNorm+GELU）在 Orin / A100 / Ascend 的高性能实现与跨平台接口对齐，单算子平均性能提升 **65%**，误差控制在 FP16 < 1e-3、INT8 < 1e-2。
> - **编译优化**：基于 Laser 编译框架搭建自动化编译流水线，完成 PyTorch → TensorRT / CANN / 自研芯片的一键编译与版本管理，解决多平台算子兼容、动态 shape、布局转换等问题。
> - **Runtime 优化**：基于 TVM Relax 优化推理 Runtime，实现内存池复用、CUDA Graph、异步 CPU/GPU 流水线，模型端到端延迟降低 **40%**，显存占用减少 **30%**。
> - **量化部署**：完成 MMBEV INT8 量化，采用分层量化、per-channel weight、per-token activation、敏感层保护等策略，精度损失 < 1%，推理速度提升 **2 倍**。
> - **推理引擎**：开发 MMBEV 专用推理引擎，支持 4/6/8 路摄像头并行输入与软硬协同调度，GPU 利用率从 60% 提升至 **85%**。
> - **多平台验证与交付**：设计跨平台 benchmark 与一致性验证方案，Orin 端到端延迟从 **100ms 优化至 30ms**，吞吐提升 **3 倍**，通过 7×24 稳定性测试与量产验证。

## 项目拆分：小项目 bullet

如果你希望简历上拆成多个独立 bullet，也可以这样写：

> **自动驾驶 BEV 多平台 HPC 算子优化**
> - 针对 BEV Pooling 和 Deformable Attention 设计 CUDA kernel，A100 延迟从 12ms 降至 4ms，Orin 延迟从 25ms 降至 10ms；Ascend 侧使用 TBE 实现对应算子，误差 < 1e-3。

> **自动驾驶模型编译与 Runtime 优化**
> - 基于 Laser 编译器实现 PyTorch → TensorRT / CANN 一键编译；基于 TVM Relax 引入内存池与 CUDA Graph，端到端延迟降低 40%，显存减少 30%。

> **自动驾驶模型量化与推理引擎**
> - 完成 MMBEV INT8 量化，NDS 损失 < 0.5%；开发专用推理引擎支持 8 路摄像头并行，GPU 利用率从 60% 提升至 85%，Orin 端到端延迟从 100ms 降至 30ms。
