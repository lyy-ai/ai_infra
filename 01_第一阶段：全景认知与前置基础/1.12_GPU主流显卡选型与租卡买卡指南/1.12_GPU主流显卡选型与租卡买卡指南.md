# 1.12 GPU 主流显卡选型与租卡买卡指南

## 课程概述

1.9 讲了 GPU 的硬件原理，本节解决工程落地问题：**手里有一个任务，到底该租哪张卡、买哪张卡？**
内容覆盖：命名体系与架构代际、主流卡规格总表、整机搭配（内存/硬盘/CPU/电源）、按场景选型、租 vs 买决策、常见避坑。

> 沿用总纲思维：选卡同样是在 **算力 / 显存容量 / 显存带宽 / 互联 / 预算** 之间做取舍，先想清楚瓶颈在哪一项。

---

## 1. 命名体系与架构代际

NVIDIA 的 AI 相关显卡分三条产品线：

| 产品线 | 代表型号 | 特点 |
|--------|----------|------|
| 数据中心计算卡 | V100 → A100 → H100/H200 → B200/GB200 | HBM 显存、NVLink、ECC、MIG，为训练与多卡集群而生 |
| 消费级显卡（GeForce） | RTX 3090 → 4090 → 5090 | 性价比之王，但显存小（24-32G）、多卡无 NVLink |
| 专业/工作站卡 | L4 / L20 / L40S、RTX 6000 Ada | 单槽/低功耗形态，介于两者之间，主打推理与图形工作站 |

**命名速记**：数据中心卡"字母 = 架构代际，数字 = 档位"——

- **A** = Ampere（2020），**H** = Hopper（2022），**B** = Blackwell（2024）
- GeForce 的 30/40/50 系也大致对应 Ampere / Ada Lovelace / Blackwell

**国内特供版（出口管制产物，务必分清）**：

| 特供型号 | 原版 | 阉割了什么 |
|----------|------|-----------|
| A800 | A100 | NVLink 600 → 400 GB/s（算力不变） |
| H800 | H100 | NVLink 900 → 400 GB/s（算力不变） |
| H20 | H100 降规 | 算力砍到 ~148 TFLOPS FP16，但保留 96G HBM3 + 4.0 TB/s 带宽 + 900 GB/s NVLink |
| L20 | L40S 降规 | 算力砍到 ~120 TFLOPS FP16 |
| 4090D / 5090D | 4090 / 5090 | 核心规模/AI 算力小幅削减 |

规律：**早期阉互联（A800/H800），后期阉算力（H20/L20/5090D）**。H20 是典型的"大带宽、低算力"推理特化卡。

### 消费级卡

| 卡 | 架构 | 显存 | 带宽 | FP16 | FP8 | FP4 | NVLink | TDP | 定位 |
|----|------|------|------|------|-----|-----|--------|-----|------|
| RTX 3090 | Ampere | 24G GDDR6X | 936 GB/s | 142 TF | - | - | 双卡 112 GB/s | 350W | 二手性价比之王，个人入门首选 |
| RTX 4090 / 4090D | Ada | 24G GDDR6X | 1008 GB/s | 165 TF | 330 TF | - | **无** | 450/425W | 个人/小团队主力，租赁市场最热门 |
| RTX 5090 / 5090D | Blackwell | 32G GDDR7 | 1792 GB/s | ~419 TF | ~838 TF | ~1676 TF | 无 | 575W | 当代消费旗舰，GDDR7 带宽接近翻倍 |

**从表中读出四个关键结论：**

1. **显存决定"能不能跑"，带宽决定"跑多快"**。LLM decode 是 memory-bound（见 1.9），同代卡推理速度大致与带宽成正比。
2. **消费卡的短板是显存容量和互联**：24-32G 天花板 + 无 NVLink，多卡只能走 PCIe（~64 GB/s），无法高效做 TP。
3. **H20/H200 这类大带宽卡是推理性价比之选**；训练要算力，必须 H100/B200 级别。
4. **代际跃迁点**：Hopper 引入 FP8，Blackwell 引入 FP4——量化推理（第 7 章）的收益与硬件代际强绑定。

## 3. 整机搭配：显存 / 内存 / 硬盘 / CPU / 电源

买卡只是整机预算的一部分，搭配不当会让卡白买：

| 部件 | 经验法则 | 说明 |
|------|----------|------|
| **内存** | ≥ 1.5–2× 总显存 | 数据加载、checkpoint 落盘缓冲、CPU offload 都吃内存；全参微调建议 2×。如 8×80G 显存 → ≥1TB DDR5 |
| **硬盘** | 系统 1TB NVMe + 数据 2–4TB NVMe | 大模型 checkpoint 动辄数百 GB（70B 全参微调一个 checkpoint ≈ 1TB+），SATA 盘会拖垮 IO；数据集大再配 NAS/HDD 冷存储 |
| **CPU/PCIe** | 多卡先看 PCIe 通道数 | 消费平台（i9/R9）仅 ~24 条通道，双卡即 x8+x8，4 卡以上必须线程撕裂者（96 条）或 EPYC（128 条），否则 H2D 带宽腰斩 |
| **电源** | 单卡 ≥850W；4×4090 ≥2000W | 4090/5090 瞬时尖峰可达 TDP 2 倍；2000W 需要 220V 16A 电路，普通 10A 插座带不动 |
| **散热** | 多卡选涡轮（blower）版 | 开放式风扇卡并排 4 张会互相加热降频；涡轮卡把热直排机箱外 |
| **形态** | SXM 卡 ≠ 能插普通服务器 | H100 SXM 必须配 HGX 底板整机（8 卡 NVSwitch）；个人/小团队只能买 PCIe 版或整机 |

## 4. 按场景选型

**显存需求速记公式**（P = 模型参数量，单位 B）：

| 任务 | 显存 ≈ | 例子（7B / 70B） |
|------|--------|------------------|
| 推理 FP16/BF16 | 2×P × 1.3（权重+KV cache+激活） | 7B≈18G / 70B≈180G |
| 推理 INT8 | 1×P × 1.3 | 7B≈9G / 70B≈90G |
| 推理 INT4 | 0.5×P × 1.3 | 7B≈5G / 70B≈45G |
| LoRA 微调 | ~2.5×P | 7B≈18G / 70B≈175G |
| 全参微调（AdamW 混合精度） | ~16×P（权重2+梯度2+优化器8+master权重4） | 7B≈112G / 70B≈1.1TB |

> 注：全参微调可用 ZeRO/FSDP 把优化器状态分摊到多卡（第 6 章），上表为"总显存池"需求。

**场景 → 推荐**：

| 场景 | 推荐配置 | 理由 |
|------|----------|------|
| 入门学习 / CUDA 课程 / 跑通课程代码 | 二手 3090 24G 或租 4090 | 最便宜的真卡环境，24G 够跑所有课程实验 |
| 7B-13B 推理 + LoRA 微调（个人开发者） | 4090 24G / 5090 32G | 单卡全覆盖，5090 的 32G + 1.8TB/s 更从容 |
| 7B-13B 全参微调 | 4×A100-80G 或 2×H100 | 需要 ~112G+ 显存池，消费卡多卡无 NVLink 效率低 |
| 70B 推理（INT4） | 单卡 H20 96G / A100-80G（勉强）；双卡 4090 | 45G+ 显存，带宽越大 decode 越快 |
| 70B 推理（FP16 生产级） | 2×H100 / H200 141G，或 4×A100-80G | 180G+ 显存池 + 高带宽 + NVLink TP |
| 高并发 LLM 推理服务 | H20 集群 或 H200 | H20 大带宽低算力恰好匹配 decode 的 memory-bound；合规现货 |
| 70B+ 预训练 | H100/H800 × 数百卡 + IB RDMA 网络 | 算力与互联缺一不可，这是集群工程不是买卡问题 |
| MoE / 长上下文 Serving | B200 / GB200 NVL72 | 192G 显存 + FP4 + NVL72 全互联 |
| 边缘部署 / 车载 | Jetson Orin 系列（见 8.2） | 功耗 15-60W，统一内存 |
| 预算极低纯学习 | 云租 T4/L4 按小时，或 Colab | 几毛钱一小时，别买卡 |

**一句话决策树**：

```text
任务是什么？
├─ 学习/实验（<7B）──────────────→ 3090/4090，租优先
├─ 推理
│   ├─ 模型能塞进单卡（INT4 后 ≤ 显存）→ 选"带宽/显存比"最高的：5090 / H20 / H200
│   └─ 塞不进单卡 → H100/H200 多卡 TP（要 NVLink，别用消费卡堆）
├─ 微调
│   ├─ LoRA → 按"2.5×P"选显存，4090/5090 通常够
│   └─ 全参 → 按"16×P"算总显存池 → A100/H100 多卡，消费卡止步
└─ 预训练 → 别买单卡，谈集群（H100/H800 + IB）
```

**回本算账示例**（4090）：

```text
买：单卡整机 ≈ ¥2.8 万（卡 1.8 万 + 整机 1 万）
租：¥2/小时
若每天用 8 小时：回本周期 = 28000 ÷ (2 × 8) = 1750 天 ≈ 4.8 年
若每天用 20 小时（推理服务）：回本周期 = 28000 ÷ (2 × 20) = 700 天 ≈ 1.9 年
```

注意 4090 这类消费卡代际更新快（2 年一代），**回本周期 > 2 年基本就是租更划算**——这解释了为什么个人学习几乎总是租、7×24 推理服务才可能买。

**决策公式**：

```text
回本周期（天） = 购卡总成本 ÷（时租价 × 日均使用小时 × 30）
```

- **日均使用 < 6 小时（利用率 < 25%）→ 租**。个人学习、突击项目、论文复现都属于这类。
- **长期 7×24 稳定高负载（利用率 > 60%）→ 买或自建**。推理服务、持续预训练属于这类。
- 别忘了买的隐性成本：整机其他部件约为卡价的 30–60%；电费（一张 4090 满载一年约 ¥3000+）；散热噪音与场地；2-3 年后的代际折旧（A100 上市 4 年后残值腰斩再腰斩）。

**买卡避坑清单**：

1. **二手矿卡/训练卡**：3090 大量来自矿场与 7×24 训练机房，到手跑 `nvidia-smi -q` 看通电时间、跑显存压力测试（如 `gpu_burn` + memtest）。
2. **4090 48G 魔改卡**：拆显存重焊的"扩容卡"，无保修、稳定性差，生产环境禁用。
3. **涡轮版 4090/5090**：多为服务器拆机或特供渠道，适合多卡机箱但噪音大，且同样要防拆机卡。
4. **SXM 卡单买无法使用**：H100 SXM 没有 HGX 底板就是一块砖。
5. **合规与时效**：4090/5090、H100/B200 对华限售（对应 D 版/H20），渠道货价格波动大且存在风险——本节的型号可得性与价格有时效性，以当下政策与行情为准。

## 6. 一页纸总结

| 你的情况 | 建议 |
|----------|------|
| 学生/转行者，跑课程与面试项目 | 租 4090（¥2/h），重度用户买二手 3090 |
| 个人开发者做 7-13B 应用 | 5090 32G（预算足）或 4090 24G |
| 小团队推理服务（70B 级） | 租 H20/H200，验证收入后再买 |
| 训练需求（全参微调/预训练） | 租 A100/H100 多卡；自建只在长期高负载时划算 |
| 任何场景 | 先用 `gpu_selector.py` 算显存，再按"带宽优先（推理）/算力优先（训练）"挑卡 |

## 代码示例

- `gpu_selector.py`：内置本节全部显卡的规格数据库（含**单卡参考价**与时租），支持三种用法：
  - `python gpu_selector.py --list`：打印全量规格对比表（显存/带宽/算力/NVLink/TDP/时租/单卡价）；
  - `python gpu_selector.py --params 70 --task inference --dtype int4`：估算显存需求，推荐单卡/多卡候选并给出**多卡总价、整机成本与租/买回本周期**；
  - `python gpu_selector.py --plot`：生成 `images/gpu_vram_bandwidth_map.png`（显存-带宽选型地图）。
