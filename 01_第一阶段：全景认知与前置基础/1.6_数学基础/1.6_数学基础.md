## 1. 线性代数

### 1.1 矩阵乘法

- `(M,K) × (K,N) = (M,N)`，FLOPs = `2·M·N·K`。
- 工程含义：GEMM 是一切性能分析的基础单位；算力利用率 = 实际 FLOPS / 峰值 FLOPS。

### 1.2 转置与访存

- 行主序（row-major）下，读 A 的行、B 的列 → B 需要转置或按列访问，否则访存不连续。
- 这是 GEMM 优化（tiling + shared memory）的数学根源。

### 1.3 分块矩阵运算

```
C = [C11 C12]   A = [A11 A12]  B = [B11 B12]
    [C21 C22]       [A21 A22]      [B21 B22]

C11 = A11·B11 + A12·B21
```

- 分块后每个子块可以独立计算 → 对应 GPU 的 block tiling。
- 也是张量并行（TP）切分权重矩阵的数学基础。

## 2. 概率论与统计

### 2.1 Softmax

$$p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

- 工程问题：数值溢出 → 实现时减去 max（`z - max(z)`），FlashAttention 的 online softmax 就是它的流式版本。
- 采样：argmax（greedy）vs 按概率采样（temperature/top-p），LLM 推理必考。

### 2.2 交叉熵损失

$$L = -\sum_i y_i \log p_i$$

- 与 softmax 联合求导有简洁形式：`dL/dz = p - y`——理解为什么框架把它们融合（fused cross entropy）。

## 3. 微积分基础

### 3.1 链式法则

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$$

- 反向传播 = 链式法则在计算图上的系统执行。
- autograd 做的就是把每个算子的局部导数按图连乘。

### 3.2 梯度含义

- 梯度指向损失上升最快的方向，优化器沿负梯度更新。
- 工程含义：梯度也是张量，形状与参数一致 → 训练显存中梯度占 4P（FP32）就是这么来的。

## 工程速查

| 场景 | 公式 |
|------|------|
| GEMM FLOPs | `2·M·N·K` |
| Attention FLOPs（每头） | `4·N²·d`（QK^T 与 softmax×V） |
| 训练显存（混合精度 Adam） | `≈16 × 参数字节` |
| Softmax 稳定化 | `softmax(z - max(z))` |
