# 1.4 学习路线总览

## 课程概述

AI Infra 知识体系庞大，没有路线很容易迷失。本节给出从前置基础到综合实战的完整学习路线，以及贯穿始终的核心思维。

---

## 1. 学习路线图

```text
第一阶段：全景认知与前置基础
  编程语言 / 数学 / Transformer / PyTorch / GPU 硬件 / 集合通信 / 工具链
        ↓
第二阶段：核心技术
  CUDA 与算子优化（HPC）
        ↓
  分布式训练（ZeRO / 3D 并行 / 通信优化）
        ↓
  推理与部署（编译器 / Runtime / 量化 / LLM Serving / 多平台适配 / 工程体系）
        ↓
第三阶段：综合项目实战
  MMBEV 端到端多平台部署优化
        ↓
第四阶段：简历包装与面试冲刺
```

## 2. 各层学习要点

| 层 | 内容 | 关键问题 |
|----|------|----------|
| 前置基础 | Python/C++、线代、Transformer、GPU、NCCL | 概念要清，能手算显存/带宽 |
| CUDA 与算子 | kernel 优化、内存层次、Tensor Core | 能手写并调优 kernel |
| 分布式训练 | DP/TP/PP、ZeRO、通信 | 能设计并行拓扑、算显存 |
| 推理与部署 | 编译、Runtime、量化、Serving | 能端到端把模型推上线 |
| 项目实战 | 全链路串起来 | 能讲清每个决策的取舍 |

## 3. 每层核心思维：牺牲了什么，换取了什么？

这是整个 AI Infra 学习的总纲，对应 1.1 的不可能三角：

| 技术 | 牺牲 | 换取 |
|------|------|------|
| ZeRO | 通信量 | 显存 |
| Activation Checkpointing | 重计算 | 显存 |
| TP | 通信带宽 | 单卡显存 |
| PP | 气泡（利用率） | 单卡显存 |
| INT8 量化 | 精度 | 显存 + 速度 |
| CUDA Graph | 灵活性 | launch 开销 |
| Continuous Batching | 调度复杂度 | 吞吐 |
| PagedAttention | 管理复杂度 | 显存利用率 |
| Speculative Decoding | draft 模型成本 | decode 速度 |
| 内存池 | 常驻显存 | 分配开销 |

**学习方法**：每学一个新技术，填一行这个表。填不出来 = 没学懂。

## 4. 学习建议

1. **自底向上打基础，自顶向下找方向**：基础课按顺序学，方向按兴趣/岗位选。
2. **每个概念配一个实验**：学完 ZeRO 就跑一次显存对比，学完 CUDA Graph 就测一次 launch 开销。
3. **输出倒逼输入**：写笔记、写代码、讲给别人听。
4. **以项目为纲**：第三阶段项目覆盖全部知识点，学每个专题时就想"这部分在项目里用在哪"。

## 本节小结

- 学习路线：前置基础 → CUDA/算子 → 分布式训练 → 推理部署 → 项目实战 → 面试冲刺。
- 核心思维：任何技术都是三角取舍，"牺牲了什么换取了什么"是最好的检验问题。
- 边学边实验、以项目为纲，知识才不会学完就忘。
