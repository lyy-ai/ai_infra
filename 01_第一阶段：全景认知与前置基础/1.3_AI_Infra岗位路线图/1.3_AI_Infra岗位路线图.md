# 1.3 AI Infra 岗位路线图

## 课程概述

AI Infra 是一个薪资高、门槛也高的方向。本节梳理从初级到高级的岗位路线图，帮你定位当前水平、明确下一步目标。

---

## 1. 级别与岗位

| 级别 | 薪资范围 | 代表岗位 |
|------|----------|----------|
| 初级 | 20k-35k/月 | 推理部署工程师、TensorRT 工程师、CUDA 工程师 |
| 中级 | 35k-60k/月 | AI Infra 工程师、编译器工程师、LLM Serving 工程师 |
| 高级 | 60k-100k/月 | AI 系统架构师、推理平台负责人、大模型基础设施负责人 |

## 2. 各级别能力要求

### 2.1 初级（0-2 年）

- 会用：TensorRT 转换模型、写基础 CUDA kernel、跑通 DDP 训练。
- 理解：GPU 基本架构、显存构成、常见并行概念。
- 产出：在指导下完成部署/优化任务。

### 2.2 中级（2-5 年）

- 独立负责：一个模块（如推理引擎的调度器、编译器的某个 pass、训练的通信优化）。
- 深入原理：能讲清 PagedAttention、ZeRO、图优化的实现细节。
- 量化思维：所有优化都有 benchmark 数据支撑。

### 2.3 高级（5 年+）

- 架构设计：设计整个训练/推理平台的架构，做技术选型。
- 跨域协同：算子 + 编译 + runtime + serving 全链路打通。
- 团队与业务：带团队，把技术指标转化为业务指标（成本、延迟、稳定性）。

## 3. 岗位方向细分

| 方向 | 核心技能 | 发展路径 |
|------|----------|----------|
| CUDA / 算子 | CUDA、HPC、Nsight | 算子专家 → 性能架构师 |
| AI 编译器 | TVM/MLIR、图优化、Codegen | 编译器工程师 → 编译器负责人 |
| 推理框架 / LLM Serving | vLLM、调度、KV Cache | Serving 工程师 → 推理平台负责人 |
| 分布式训练 | ZeRO、3D 并行、NCCL | 训练工程师 → 训练 Infra 负责人 |
| 推理部署（边缘） | TensorRT、量化、C++ | 部署工程师 → 端侧架构师 |
| AI Infra 综合 | 上述多项 + 系统设计 | Infra 工程师 → 架构师 |

## 4. 成长建议

1. **初级先深一个方向**：先把 CUDA/部署做扎实，不要贪多。
2. **中级建"T 型"能力**：一个方向专家级 + 相邻方向能对话。
3. **高级补系统与业务**：架构设计、成本意识、团队影响力。
4. **持续积累可量化成果**：每个项目都留下 benchmark 数字，这是晋升和跳槽的硬通货。

## 本节小结

- 初级靠"会用 + 扎实基础"，中级靠"独立负责 + 原理深度"，高级靠"架构 + 业务转化"。
- 选一个主方向深挖，同时保持对相邻方向的理解。
- 薪资与"能量化的影响力"正相关：延迟降多少、成本省多少、稳定性提升多少。
