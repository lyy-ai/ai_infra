## 题目标注说明

每题按统一格式组织：

- **公司画像**：LLM（大模型公司）/ 芯片（芯片厂）/ 云（云厂商与平台团队）/ 车（自动驾驶与具身智能）——不同画像的团队考察侧重不同，投递前按目标公司画像优先刷对应题。
- **难度**：基础（人人会，答错扣分）/ 进阶（合格线）/ 深入（加分项）。
- **一句话答案**：面试时的开场回答（30 秒内说完）。
- **展开**：被追问时的支撑细节。
- **追问**：该题的典型追问方向与答案。

## 使用建议

1. **第一遍按模块刷**：每学完 02-07 的一章，刷对应题库的题，用题目检验讲义掌握度。
2. **第二遍按画像刷**：拿到面试邀约后，按公司画像过滤重点题（如投芯片厂重点刷 14.1 的深入题，投大模型公司重点刷 14.2/14.5）。
3. **手写题单独练**：14.7 的题要真的限时动手写，尤其 Q1-Q4（Softmax/Reduce/KV 分配器/CB 调度器）达到肌肉记忆。
4. **新热点题决定上限**：14.5 是 2024-2026 的新考点，面试官用它区分"背八股"和"跟前沿"——本仓库 12/13 章是这部分的弹药库。
5. **系统设计背框架不背答案**：14.6 的评分看过程（澄清→估算→分层→取舍），框架记熟，数字会算。
