# 16.3 开源数据集与数据配比

> 学习目标：掌握主流开源预训练数据集的格局与质量层级、数据配比（data mixing）的方法论（DoReMi/RegMix/DoGE），以及 token 预算分配的训练侧依据。

## 1. 为什么开源数据集是研究热点

2023 年前，大模型数据集是各家机密；2024 年起形势反转——HuggingFace（FineWeb）、苹果牵头的 DCLM、AI2（Dolma/OLMo）、NVIDIA（Nemotron-CC）相继开放**数据集本身与完整生产工艺**。原因：

- 开源模型要证明"能力来自数据而非秘方"，数据集开放是可信度基础。
- 数据处理的实验（过滤策略、配比）需要可复现的对照基准——DCLM 的定位就是"数据研究的 ImageNet"。
- 对学习者的意义：**第一次可以亲手复现"顶级预训练数据是怎么造的"**——这是 Data Infra 入门的最佳路径。

## 2. 主流开源数据集档案

| 数据集 | 出品 | 规模 | 特点 |
|--------|------|------|------|
| **FineWeb / FineWeb-Edu** | HuggingFace | 15T token（Edu 子集 1.3T） | Common Crawl 精滤，处理管线（datatrove）全开源；Edu 子集用教育性分类器筛选，是中小模型训练的热门选择 |
| **DCLM-Baseline** | DCLM 团队（苹果/华盛顿大学等） | 3.8T token（完整池 240T 原始网页） | 研究导向：每个处理决策都有对照实验支撑；配套训练框架与评测协议 |
| **RedPajama v2** | Together AI | 30T token | Llama 数据配方的开放复刻，Common Crawl 五语 |
| **Dolma** | AI2 | 3T token | OLMo 模型配套，来源多样（网页/论文/代码/书籍），tagging 体系完整 |
| **Nemotron-CC** | NVIDIA | 6.3T token | GPU 加速管线（NeMo Curator）产物，含合成改写数据 |
| **The Pile** | EleutherAI | 800GB | 早期经典（GPT-Neo 时代），22 个子集 |

**选型经验**：从零训练中文/多语模型看 FineWeb + 中文专项（如 CCI 类中文语料）；做数据消融研究用 DCLM（实验协议最严谨）；快速起步用 FineWeb-Edu（质量/规模平衡最好）。

## 3. 数据配比（Data Mixing）——被低估的第一变量

多领域数据（网页/代码/数学/书籍/多语）按什么比例混合训练，对模型能力结构的影响不亚于数据质量本身。

**三类方法**：

1. **经验配方（主流）**：参考公开配比 + 小规模消融实验调整。公开锚点：Llama 类配比（网页约 80%+，代码/数学/书籍各几个点）；DeepSeek 系提高数学/代码权重。
2. **DoReMi**（Google，2023）：先训一个小参考模型，用 group DRO 优化各域权重使各域 excess loss 最均衡，再把配比迁移到大模型训练——"小模型试配比、大模型用结果"范式的开创者。
3. **RegMix / DoGE 等回归类方法**：用大量小模型在不同配比下训练，拟合"配比→验证 loss"的回归模型，外推预测最优配比——比 DoReMi 更系统化，样本效率更高。

配套脚本 `data_mixing_simulator.py` 模拟了"配比影响能力"的基本现象与 RegMix 式回归搜索的思路。

**实践要点**：
- 配比不是一次性的：训练中后期调整配比（annealing 阶段提高高质量数据占比）是常见技巧。
- 评估配比要用"能力剖面"（多 benchmark 雷达图），单一 loss 会掩盖结构性变化。
- 上采样高质量小数据集（重复多 epoch）与下采样低质大数据集，等价于一种软配比。

## 4. Token 预算与数据规模规划

- **Chinchilla 口径**：计算最优下 token 数 ≈ 20 × 参数量；但 2024 后主流大模型大幅"超训"（Llama 3 8B 训 15T，远超最优）——推理成本考量使"小模型 + 多数据"成为产品主流。
- **数据墙问题**：高质量公开文本的总量有限（数十 T token 级），万亿级训练逼近天花板——这是合成数据（16.4 节）崛起的根本动因。
- **预算分配**：token 预算在预训练/退火/后训练间的划分也是配方的一部分（如 80% 预训练 + 15% 长上下文扩展 + 5% 退火精调）。

## 5. 数据集评估清单（拿来用之前先过一遍）

- [ ] 处理管线是否公开可审计（过滤规则、去重方法、去污报告）？
- [ ] 来源构成与领域分布是否清楚（有无 domain 标注）？
- [ ] 许可证是否允许商用（FineWeb/DCLM 都有明确条款，Common Crawl 衍生品的版权灰区要知道）？
- [ ] 分词后实际 token 数（文档数 × 平均长度，别只看文件大小）？
- [ ] 与目标评测集的污染检测报告？

## 7. 面试视角

- **Q：数据配比对模型有什么影响？** A：决定能力结构——代码比例影响编程能力、数学影响推理；配比失当会出现"总 loss 降但关键能力不涨"；DoReMi/RegMix 是用小模型实验搜索配比的方法论。
- **Q：为什么现在都"超训"（over-train）？** A：Chinchilla 最优是训练成本最优，但推理成本按参数量算——小模型多训数据，全生命周期（训练+部署）总成本更低。
- **Q：开源数据集里质量最高的是哪几个？** A：FineWeb（尤其 Edu 子集）、DCLM-Baseline、Nemotron-CC 是当前公认的第一梯队，且生产工艺全部开放可复现。
