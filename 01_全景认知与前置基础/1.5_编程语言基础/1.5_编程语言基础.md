# 1.5 编程语言基础

## 课程概述

AI Infra 工程是 Python 与 C++ 的双语世界：Python 负责框架与胶水层，C++ 负责性能关键路径。本节补齐后面所有专题需要的语言基础。

---

## 1. Python 进阶

### 1.1 面向对象

- `__init__` / `__call__` / `__enter__/__exit__`（context manager）。
- MRO 与 `super()`：理解 PyTorch Module 的多重继承。

### 1.2 装饰器

```python
import functools, time

def timing(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        r = fn(*args, **kwargs)
        print(f"{fn.__name__}: {(time.perf_counter()-t0)*1e3:.2f}ms")
        return r
    return wrapper
```

应用场景：benchmark 计时、profiling 打点、分布式 rank 检查。

### 1.3 生成器

- `yield` 惰性求值：处理大数据集时避免一次性加载（dataloader 的思想基础）。
- 生成器表达式省内存：`(x*x for x in range(10**8))`。

### 1.4 多进程 / 多线程

| 方式 | 适用 | 原因 |
|------|------|------|
| threading | IO 密集 | GIL 限制 CPU 并行 |
| multiprocessing | CPU 密集 | 绕过 GIL，DDP 每 rank 一个进程 |
| asyncio | 高并发 IO | serving 网关常用 |

## 2. C/C++ 核心

### 2.1 指针与内存管理

- 指针、引用、数组衰减。
- 栈 vs 堆：`new/delete`、`malloc/free`。
- 智能指针：`unique_ptr` / `shared_ptr`——现代 C++ 必备，TensorRT 插件、推理引擎代码大量出现。

### 2.2 编译链接

```text
.cpp → 预处理 → 编译(.o) → 链接(可执行/库)
- 静态库 .a / 动态库 .so
- CMake：target_link_libraries、include_directories
```

CUDA 工程常见：`nvcc` 编译 `.cu`，与 C++ 目标文件链接。

### 2.3 模板基础

- 函数模板 / 类模板：理解 `template<typename T> void kernel(T* data)`。
- 模板特化：CUDA kernel 常按 dtype 特化（half / float / int8）。

## 3. Python/C++ 混合开发（pybind11）

```cpp
#include <pybind11/pybind11.h>

int add(int a, int b) { return a + b; }

PYBIND11_MODULE(my_ops, m) {
    m.def("add", &add, "add two ints");
}
```

编译后 Python 直接 `import my_ops`。这是自定义算子接入 PyTorch 的标准路径（PyTorch extension 底层即 pybind11）。
