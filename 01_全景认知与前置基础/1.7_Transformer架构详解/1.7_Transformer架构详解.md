# 1.7 Transformer 架构详解

## 课程概述

Transformer 是所有大模型的骨架，也是 AI Infra 优化的主战场。本节从工程视角拆解：每个组件的计算过程、复杂度来源、以及由此引出的优化点。

---

## 1. Self-Attention 机制

### 1.1 计算过程

$$Q = XW_Q,\quad K = XW_K,\quad V = XW_V$$
$$A = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right),\quad O = AV$$

### 1.2 O(N²) 复杂度本质

- QK^T：`(N,d) × (d,N) = (N,N)`，FLOPs = 2N²d，显存 N²。
- 序列 N 翻倍 → 计算与显存 ×4。
- **这就是 FlashAttention（不落 N² 矩阵）、PagedAttention（管理 KV）、稀疏/滑窗 attention 存在的根本原因。**

### 1.3 训练 vs 推理

- 训练：整段序列一次算完（parallel），瓶颈在 N² 矩阵。
- 推理 decode：每步只算新 token 与历史 K/V 的点积（N×d），瓶颈在 **KV Cache 的显存读取带宽**——decode 是 memory-bound。

## 2. 前馈网络（FFN）

$$\text{FFN}(x) = W_2\,\sigma(W_1 x + b_1) + b_2$$

- 两层线性变换，中间维度通常 4×hidden。
- FFN 占模型参数量约 2/3 → 量化/TP 切分的主要对象。

## 3. 位置编码

| 方法 | 公式/思想 | 工程影响 |
|------|-----------|----------|
| Sinusoidal | 正弦/余弦固定函数 | 无参数，外推差 |
| RoPE | 旋转位置编码：q/k 乘旋转矩阵 | LLaMA 系标配；长序列外推需 NTK/YaRN 插值 |

RoPE 工程点：对 q、k 施加旋转变换（复数乘法视角），kernel 中常融合进 attention。

## 4. LayerNorm 与残差连接

| 结构 | 形式 | 特点 |
|------|------|------|
| Post-Norm | `LN(x + sublayer(x))` | 原始 Transformer，训练不稳定 |
| Pre-Norm | `x + sublayer(LN(x))` | 现代 LLM 标配，梯度更稳 |

工程点：LayerNorm + 残差常与前后算子融合成单个 kernel（fusion）。

## 5. 完整前向过程

```text
token ids
  → Embedding (查表)
  → ×L 个 Decoder Block:
      Pre-LN → Multi-Head Attention → +残差
      Pre-LN → FFN → +残差
  → Final LN
  → LM Head (与 embedding 共享权重)
  → logits → softmax → 采样 → 下一个 token（自回归）
```

自回归生成：每步只算 1 个新 token，但复用全部历史 KV Cache。

## 6. Attention 变种演进

| 变种 | K/V 头数 | KV Cache 大小 | 代表 |
|------|----------|---------------|------|
| MHA | = Q 头数 | 1× | 原始 |
| MQA | 1 | 1/h | 速度快、质量略降 |
| GQA | g（如 8） | g/h | LLaMA2-70B 等主流折中 |
| MLA | 低秩压缩 | 更小 | DeepSeek-V2/V3，压缩 KV 为低秩 latent |

**Infra 视角**：KV Cache 大小 = `2 × L × (KV头数) × head_dim × seq × batch × 2字节`。GQA/MLA 的核心收益就是把 KV Cache 降下来，从而支撑更长序列与更大 batch。

## 本节小结

- Attention 的 N² 复杂度与 decode 的 memory-bound 特性，决定了推理优化两大方向：少算（FlashAttention）与少读（KV Cache 管理）。
- FFN 占参数大头 → 量化与 TP 的主战场。
- MHA→MQA→GQA→MLA 的演进主线就是压缩 KV Cache。
- 记住每个组件，后面的算子融合、量化敏感层、并行切分都在这里发生。
