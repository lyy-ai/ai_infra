# 简历项目：前置基础自查清单

第 1 章不直接产出简历项目，但它决定了后面项目能否真正理解。本节把前置基础转化为**可自查、可在面试中直接使用**的清单。

## 一、必会心算清单（面试现场直接用）

| 问题 | 公式 | 示例 |
|------|------|------|
| GEMM FLOPs | 2·M·N·K | 4096³ GEMM = 137 GFLOP |
| 训练显存（Adam 混合精度） | ≈16 × P 字节 | 7B → ~112GB（不含激活） |
| KV Cache/token | 2·L·kv_heads·head_dim·2B | 7B(32层GQA8×128) ≈ 0.26MB |
| Ring AllReduce 通信量 | ≈2S（与 N 无关） | 1GB 梯度 → 每 rank 收发 2GB |
| decode 时间下界 | 权重字节数 / HBM 带宽 | 7B FP16 on A100 ≈ 14GB/2TBps ≈ 7ms |
| roofline 拐点 | 算力/带宽 | A100 ≈ 200 FLOP/byte |

## 二、概念一句话清单（自查是否真懂）

- [ ] 不可能三角：计算、通信、显存的取舍关系，能举 5 个例子。
- [ ] FlashAttention：online softmax + 分块，N² 矩阵不落 HBM。
- [ ] GQA：KV 头共享，KV Cache 降为 g/h。
- [ ] Memory Wall：算术强度低于拐点就 memory-bound。
- [ ] NVLink vs IB：差一个数量级，决定 TP 节点内、PP/DP 跨节点。
- [ ] AllReduce = ReduceScatter + AllGather。
- [ ] autograd 保存激活 → 训练显存的直觉来源。
- [ ] SIMT / warp / Tensor Core：GPU 执行模型三要素。
