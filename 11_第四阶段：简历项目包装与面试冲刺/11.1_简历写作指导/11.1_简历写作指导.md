# 11.1 简历写作指导

## 本节目标

技术做得再好，简历写不出来也拿不到面试。本节教你把前面三个阶段的项目经验，用 STAR 法则和量化指标包装成有竞争力的简历 bullet，并匹配目标岗位 JD。

---

## 一、STAR 法则包装技术亮点

### 1.1 STAR 是什么

| 字母 | 含义 | AI Infra 简历中的写法 |
|------|------|----------------------|
| S - Situation | 背景 | 什么业务、什么模型、什么平台、遇到什么问题 |
| T - Task | 任务 | 你负责什么模块、目标是什么 |
| A - Action | 行动 | 用了什么技术、怎么做的（技术栈关键词） |
| R - Result | 成果 | 量化指标（延迟、吞吐、显存、精度、利用率） |

### 1.2 反面 vs 正面示例

❌ 空泛描述（不要这样写）：

> 负责模型部署优化，提升了推理性能，参与了量化工作。

✅ STAR + 量化（要这样写）：

> 针对自动驾驶 MMBEV 模型在 Orin 上延迟 100ms、无法满足实时性的问题（S），负责端到端部署优化（T），通过自定义 BEV Pooling CUDA kernel、TVM Relax 内存池与 CUDA Graph、INT8 分层量化（A），将端到端延迟降至 30ms、吞吐提升 3 倍、显存减少 30%，通过量产验证（R）。

### 1.3 STAR 简化版

日常简历 bullet 常用“**问题 → 行动 → 结果**”三段式，S/T 合并：

> **背景**（1 句）→ **职责/行动**（2-4 句，带技术栈）→ **成果**（1-2 句，全量化）

## 二、量化成果表达

### 2.1 可量化的维度

| 维度 | 表达模板 |
|------|----------|
| 延迟 | 从 X ms 优化至 Y ms / 降低 Z% |
| 吞吐 | 提升 X 倍 / 达到 Y tokens/s、FPS |
| 显存 | 减少 X% / 从 A GB 降至 B GB |
| 精度 | 损失控制在 X% 以内 / NDS 损失 0.4% |
| 算力利用率 | 从 X% 提升至 Y% |
| 效率 | 测试/编译/验证时间从 X 缩短至 Y |
| 规模 | 支持 N 卡 / M 路输入 / K 平台 |

### 2.2 量化数字从哪里来

- benchmark 数据（自己跑的，必须真实可复现）
- 前后对比（优化前 baseline 一定要留）
- 线上监控（生产环境真实指标最有说服力）

⚠️ 红线：**不要编造数字**。面试官深挖"30ms 是在什么 batch、什么输入分辨率下测的"时答不上来，比不写更糟。

---

## 三、简历项目写作黄金法则

1. **量化成果**：所有项目必须包含可量化指标（延迟降低 XX%、吞吐量提升 XX 倍、显存占用减少 XX%），避免空泛描述。
2. **突出技术栈**：明确写出技术关键词（CUDA、TVM/Relax、Laser、CANN、vLLM、FlashAttention、DeepSpeed 等），匹配岗位 JD。
3. **体现业务价值**：说明项目解决了什么业务问题（满足实时性要求、支持量产部署、降低推理成本），不只写技术细节。
4. **分层描述**：项目描述分为 背景→职责→成果 三层，逻辑清晰，重点突出。

## 四、岗位面试侧重点（参考）

| 岗位方向 | 核心考察点 |
|----------|------------|
| CUDA / 算子优化 | GPU 架构、CUDA 编程、HPC 基础、手写 Kernel |
| AI 编译器 | TVM 架构、图优化、Codegen、动态 Shape |
| 推理框架 / LLM Serving | vLLM 原理、PagedAttention、KV Cache、Continuous Batching |
| 分布式训练 | ZeRO、3D 并行、Megatron-LM、通信优化 |
| 推理部署（车企/边缘） | TensorRT、TVM、量化、C++ 功底、实时性 |
| AI Infra（综合） | 项目深挖 + 系统设计 + 上述多方向组合 |

### 4.1 JD 匹配策略

1. 读 JD，圈出技术关键词。
2. 在简历项目中找到对应技术栈的 bullet，提前到最显眼位置。
3. 面试自我介绍时，主动按岗位方向选择项目重点：
   - 算子岗 → 重点讲 HPC kernel、warp 优化、bank conflict。
   - 编译器岗 → 重点讲 Laser/TVM、图优化 pass、动态 shape。
   - 推理框架岗 → 重点讲 vLLM、PagedAttention、Continuous Batching。
   - 训练岗 → 重点讲 ZeRO、3D 并行拓扑、通信优化。

## 本节小结

- STAR 法则的核心是让面试官看到：你在什么约束下、用了什么技术、拿到什么结果。
- 量化数字是简历的灵魂，但必须真实、可复现、经得起深挖。
- 一份简历打天下不如按岗位 JD 定制：算子、编译器、推理框架、训练各有侧重。
