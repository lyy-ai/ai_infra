# 3.8 Relay 到 Relax Pass 迁移实战

## 课程概述

TVM 正在从 Relay 向 Relax 迁移。Relay 是静态图函数式 IR，积累了丰富的 Pass 和优化经验；Relax 是新一代动态图 IR，支持动态 shape、控制流、call_tir 等现代抽象。很多项目既有的 Relay Pass 需要迁移到 Relax，同时要保持性能一致。

本节把迁移实战拆成三块：为什么迁移、迁移方法论、Relax Pass 写法、P1 allspark 后端特性开发。

学完本节后，你应该能够：

- 对比 Relay 和 Relax 的 IR 抽象差异。
- 把简单的 Relay Pass 改写为 Relax Pass。
- 处理动态 shape、call_tir、BlockBuilder 等新机制。
- 为 allspark 后端开发 Relax 特性适配。

---

## 1. 为什么从 Relay 迁移到 Relax

| 场景 | Relay | Relax |
| ---- | ----- | ----- |
| 动态 shape | 弱，需 bucket 或 VM | 原生支持 |
| 控制流 | 有限 | 原生支持 if/while |
| 大模型 | 笨重 | 设计目标 |
| 算子语义 | 函数式 | 绑定式 + call_tir |
| Pass 写法 | ExprMutator | BlockBuilder + builder.get() |

迁移的核心驱动力：

- 大模型推理需要动态 batch 和 sequence length。
- MoE 架构需要动态路由和专家选择。
- 控制流（如循环 decode）需要原生表达。
- call_tir 让高层图与底层 TIR 解耦，便于后端优化。

---

## 2. 关键抽象差异

### 2.1 Relay 函数式表达

```python
from tvm import relay

x = relay.var("x", shape=(1, 784))
w = relay.var("w", shape=(784, 128))
y = relay.nn.dense(x, w)
func = relay.Function([x, w], y)
```

Relay 图是嵌套表达式，无副作用，用 `Function` 表达输入输出关系。

### 2.2 Relax 绑定式表达

```python
from tvm import relax
from tvm.relax.frontend import nn

class Linear(nn.Module):
    def __init__(self):
        self.w = nn.Parameter((784, 128), "float32")
    def forward(self, x: nn.Tensor):
        return nn.matmul(x, self.w)

mod, _ = Linear().export_tvm(
    spec={"forward": {"x": nn.spec.Tensor([1, 784], "float32")}}
)
```

Relax 使用 `BindingBlock` 顺序组织变量赋值，算子通过 `call_tir` 调用底层 TIR。

### 2.3 call_tir 的作用

```python
from tvm import relax, tir

# Relax 层：调用 TIR PrimFunc
out = relax.call_tir("matmul_tir", [x, w], out_sinfo=...)
```

call_tir 是 Relax 与 TIR 的桥梁，让高层图保持抽象，底层优化下放到 TIR。

## 3. Relay Pass 迁移到 Relax 的方法论

迁移一个 Pass 通常需要：

1. 把 `relay.Function` 改写为 `relax.Function`。
2. 把 `relay.expr` 操作改为 `relax.expr` 操作。
3. 把 `relay.transform` 注册改为 `relax.transform` 注册。
4. 处理动态 shape 和 `call_tir` 调用。
5. 用 `BlockBuilder` 重构函数体。

### 3.1 Relay Pass 示例

```python
from tvm import relay
from tvm.relay import transform as T

@T.function_pass(opt_level=1)
class MyRelayPass:
    def __init__(self):
        pass

    def transform_function(self, func, mod, ctx):
        # 使用 ExprMutator 改写 func.body
        mutator = MyRelayMutator()
        new_body = mutator.visit(func.body)
        return relay.Function(func.params, new_body, func.ret_type, func.type_params, func.attrs)
```

### 3.2 Relax Pass 等价写法

```python
from tvm import relax
from tvm.relax import transform as T
from tvm.relax.dpl import pattern, rewrite

@T.function_pass(opt_level=1)
class MyRelaxPass:
    def __init__(self):
        pass

    def transform_function(self, func, mod, ctx):
        # 使用 BlockBuilder 重构函数体
        builder = relax.BlockBuilder(mod)
        with builder.function(name=func.name_hint, params=func.params):
            # 遍历并改写 body
            out = self.rewrite(func.body, builder)
            builder.emit_func_output(out)
        return builder.get()[func.name_hint]
```

### 3.3 迁移检查清单

| 检查项 | Relay | Relax |
| ------ | ----- | ----- |
| 函数定义 | `relay.Function` | `builder.function()` |
| 变量创建 | `relay.var()` | `builder.emit()` |
| 类型信息 | `checked_type` | `struct_info` |
| 常量 | `relay.const()` | `relax.const()` |
| 调用 | `relay.Call` | `relax.call_tir` / `relax.call_pure_packed` |
| Pass 注册 | `relay.transform.function_pass` | `relax.transform.function_pass` |

## 4. Relax Pass 实战：合并冗余 MatMul BiasAdd

下面把 Relay 中常见的 `matmul + bias_add` 融合迁移到 Relax。

### 4.1 Relay 版本

```python
from tvm import relay
from tvm.relay.dataflow_pattern import is_op, wildcard, rewrite

class FuseMatmulBiasAddRelay(DFPatternCallback):
    def __init__(self):
        self.pattern = is_op("nn.bias_add")(is_op("nn.matmul")(wildcard(), wildcard()), wildcard())

    def callback(self, pre, post, node_map):
        matmul = node_map[self.pattern][0].args[0]
        bias = node_map[self.pattern][0].args[1]
        return relay.nn.matmul_bias_add(matmul.args[0], matmul.args[1], bias)

mod = rewrite.FuseMatmulBiasAddRelay()(mod)
```

### 4.2 Relax 版本

```python
from tvm import relax
from tvm.relax.dpl import pattern, rewrite

matmul_pat = pattern.is_op("relax.matmul")(pattern.wildcard(), pattern.wildcard())
bias_add_pat = pattern.is_op("relax.add")(matmul_pat, pattern.wildcard())

class FuseMatmulBiasAddRelax(rewrite.PatternRewriter):
    def __init__(self):
        super().__init__()

    def rewrite(self, expr):
        # 使用 DPL 模式匹配和重写
        if match := self.match(bias_add_pat, expr):
            x, w, b = match[matmul_pat].args[0], match[matmul_pat].args[1], match[bias_add_pat].args[1]
            return relax.call_tir("fused_matmul_bias_add", [x, w, b], out_sinfo=...)
        return expr

mod = FuseMatmulBiasAddRelax().rewrite_module(mod)
```

注意：Relax 中通常通过 `call_tir` 调用融合的 TIR PrimFunc，而不是直接引入新的 Relax 算子。

## 5. P1 allspark 后端特性开发

allspark 是项目内部后端，需要适配 Relax 的 call_tir 语义。

### 5.1 allspark 后端 Legalize

```python
from tvm import relax, tir
from tvm.relax import transform as T

@T.function_pass(opt_level=1)
class AllsparkLegalizePass:
    def __init__(self):
        pass

    def transform_function(self, func, mod, ctx):
        # 把 Relax 算子转换为 allspark 后端可识别的 TIR PrimFunc
        new_body = self.legalize(func.body)
        return relax.Function(
            func.params,
            new_body,
            func.ret_struct_info,
            func.attrs,
        )

    def legalize(self, expr):
        if isinstance(expr, relax.Call) and expr.op.name == "relax.matmul":
            # 替换为 allspark 特定的 call_tir
            return relax.call_tir("allspark.matmul", expr.args, out_sinfo=expr.struct_info)
        return expr
```

### 5.2 allspark 后端适配点

- 算子支持清单：allspark 只支持部分 Relax 算子，需要 Legalize Pass 把不支持的算子替换为等价实现或切分子图。
- 动态 shape：allspark 对动态维度有限制，需要 shape 推导和约束传播。
- 内存布局：allspark 可能有特定 NCHW/NHWC 要求，需要 Layout 适配。
- 产物格式：allspark 通常输出 `.aom` 格式，需要 Artifact Packager 定制。

## 7. 常见误区

### 7.1 “Relay Pass 可以直接在 Relax 上跑”

Relay 和 Relax 的 IR 节点类型不同（`relay.Call` vs `relax.Call`），Pass 需要重写。但优化思路（如 DCE、融合）可以复用。

### 7.2 “Relax 只是 Relay 的动态版本”

Relax 不仅是动态 shape，还引入了绑定式语义、call_tir、BlockBuilder 等新抽象。Pass 写法与 Relay 有显著差异。

### 7.3 “迁移只需要改 API 名”

迁移需要理解新的 IR 语义，尤其是动态 shape、struct_info、call_tir 对 Pass 不变性的影响。直接改 API 名会导致错误。

---

## 8. 本节小结

1. 从 Relay 迁移到 Relax 的核心驱动力是动态 shape、控制流和大模型需求。
2. Relay 是函数式静态图 IR，Relax 是绑定式动态图 IR，支持 call_tir。
3. Pass 迁移需要改写 IR 节点操作、类型信息、注册方式，并用 BlockBuilder 重构函数体。
4. allspark 后端需要 Legalize Pass 把 Relax 算子转换为后端可识别的 TIR PrimFunc。
5. 迁移不仅是 API 改名，更是 IR 语义和优化策略的适配。
