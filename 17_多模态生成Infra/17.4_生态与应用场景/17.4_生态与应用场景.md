# 17.4 生态与应用场景

> 学习目标：摸清多模态生成的开源生态（框架/模型/工具链）、主要应用场景的工程形态、以及 LLM Infra 技能向生成方向的迁移路径。

## 1. 开源生态地图

```text
模型层   │ FLUX / SD3.5 / SDXL（图像）；Wan / HunyuanVideo / CogVideoX（视频）
框架层   │ Diffusers（代码优先）/ ComfyUI（节点图优先）/ LightX2V（视频推理优化）
并行层   │ xDiT（USP/CFG/PipeFusion）
工具链   │ ControlNet / LoRA 生态 / IP-Adapter（可控生成）
评测     │ VBench（视频）/ GenEval（图文一致性）/ 人评平台
```

**关键项目档案**：

| 项目 | 定位 | 仓库 |
|------|------|------|
| **Diffusers** | HF 的生成模型标准库：模型/调度器/管线统一 API，代码优先路线的底座 | github.com/huggingface/diffusers |
| **ComfyUI** | 节点图工作流事实标准，原型与内容生产的中心 | github.com/comfyanonymous/ComfyUI |
| **xDiT** | DiT 推理并行框架（17.3 节） | github.com/xdit-project/xDiT |
| **LightX2V** | 视频生成推理优化框架（步数蒸馏/量化/卸载的整合） | github.com/ModelTC/LightX2V |
| **Wan2.x** | 阿里开源视频模型（1.3B 消费卡可跑 / 14B 旗舰） | github.com/Wan-Video |
| **VBench** | 视频生成评测基准（多维度自动评分） | github.com/Vchitect/VBench |

## 2. 应用场景与工程形态

### 2.1 内容生产（广告/电商/营销）

最大规模落地场景：商品图、营销视频、创意素材的批量生成。
- 工程形态：**异步批量管线**（离线吞吐优先）——夜间跑满 GPU 池，是混部填谷的理想负载。
- 关键指标：单位素材成本、合格率（人工筛选比例）、可控性（LoRA 定制品牌风格）。

### 2.2 游戏与影视

游戏资产（贴图/概念图/动作预演）、影视分镜与预演。
- 工程形态：ComfyUI 工作流 + 艺术家在环——生成是辅助而非替代，人机协作界面重要。
- 关键指标：迭代速度（艺术家等不起分钟级）、风格一致性。

### 2.3 世界模型与自动驾驶仿真

视频生成模型作为"可编程世界模拟器"：生成驾驶场景用于训练/测试自动驾驶（各家自动驾驶公司的前沿方向）。
- 工程形态：与仿真管线集成；可控性（场景编辑、极端案例生成）是核心需求。
- 对本仓库读者的特殊意义：这是生成 Infra 与自动驾驶（MMBEV 项目背景）的交汇点。

### 2.4 实时与交互场景（前沿）

少步蒸馏 + 并行使"秒级出图"成为可能，实时交互生成（游戏 NPC 形象、实时风格化视频流）正在开启——这类场景对延迟的要求开始向 LLM serving 看齐。

## 3. LLM Infra → 生成 Infra 的技能迁移表

| 已有技能（本仓库章节） | 在生成 Infra 中的对应 |
|----------------------|----------------------|
| FlashAttention/kernel 优化（02） | DiT attention 优化，完全同款 |
| 量化 INT8/FP8（07） | DiT 量化（注意敏感层策略） |
| Ring Attention/CP（5.12） | xDiT USP 序列并行（且无需 zigzag） |
| Pipeline 并行（6.5） | PipeFusion 去噪步流水 |
| 显存分层/offload（5.12） | 文本编码器卸载、VAE 分块、层 offload |
| 混部与调度（9.6） | 生成任务填谷 |
| 性能回归体系（9.2） | 生成质量回归（美学分+人评） |
| **新学** | 步数蒸馏、CFG 优化、缓存复用、异步任务型 serving |

**结论**：约 70% 技能直接迁移，新增的 30% 集中在"迭代式生成"特有的优化（步数/CFG/缓存）与异步负载形态——LLM Infra 工程师转入生成方向的学习曲线很平缓。

## 4. 岗位观察

多模态生成 Infra 的岗位集中在：短视频/内容平台（字节/快手）、电商（阿里）、游戏（腾讯/网易/米哈游）、自动驾驶仿真、模型公司（智谱/月之暗面等的视频团队）。JD 高频要求：Diffusion/DiT 原理、CUDA 优化、分布式推理、ComfyUI/Diffusers 生态——与本仓库主线的重合度极高，是 LLM Infra 求职者的自然第二方向。

## 6. 面试视角

- **Q：LLM Infra 经验对生成模型 Infra 有多大用？** A：约七成直接迁移（kernel/量化/序列并行/显存管理/调度回归体系），新增的是迭代式生成特有优化（步数蒸馏/CFG/缓存）与异步任务型负载形态。
- **Q：生成模型的主要落地场景？** A：内容生产（批量异步管线）、游戏影视（人在环工作流）、世界模型与自动驾驶仿真、以及前沿的实时交互生成。
- **Q：ComfyUI 和 Diffusers 怎么选？** A：原型与内容生产用 ComfyUI（生态+可视化）；大规模深度优化的生产 serving 用 Diffusers 直跑（可控性）。
