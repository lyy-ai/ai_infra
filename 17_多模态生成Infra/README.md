# 第十七章：多模态生成 Infra

视频/图像生成模型（DiT/扩散/流匹配）的推理系统与优化。生成模型推理的主要矛盾与 LLM 不同——**LLM 是显存与带宽，生成是算力与延迟**——因此有独立的优化工具箱（步数蒸馏/CFG 优化/缓存复用/生成并行）。LLM Infra 约七成技能可直接迁移，本章聚焦新增的三成。

## 目录结构

```

│   ├── 17.1_生成模型推理基础.md
│   └── dit_cost_estimator.py       # 分辨率/帧数/步数/CFG 的成本杠杆估算
├── 17.2_生成模型推理优化/          # 步数压缩/引导蒸馏/DeepCache-TeaCache-PAB/量化与编译/显存管理
│   └── 17.2_生成模型推理优化.md
├── 17.3_视频生成系统与并行/         # xDiT 四件套(USP/CFG/PipeFusion)/异步任务型serving/ComfyUI

│   └── parallel_dit_sim.py         # CFG并行与USP序列并行的加速比模拟

```

## 各节速览

| 节 | 核心内容 | 一句话收获 |
|----|---------|-----------|
| 17.1 推理基础 | 三段式架构、T 步 × CFG×2 的成本结构、序列长度平方爆炸 | 生成推理贵在三重乘法：步数×前向×CFG，再乘序列平方 |
| 17.2 推理优化 | 求解器→步数蒸馏→引导蒸馏→缓存→量化编译的推荐顺序 | 步数压缩收益最大，缓存免训练，每步都要问质量代价 |
| 17.3 系统与并行 | xDiT（USP/CFG 并行/PipeFusion）、异步任务型 serving、ComfyUI 工程化 | CFG 并行白送 2 倍，USP 是 ring attention 的 DiT 版 |
| 17.4 生态与场景 | 生态地图、内容生产/游戏影视/世界模型/实时交互、技能迁移 | LLM Infra 七成技能直接迁移，转方向成本低 |

## 运行示例

```bash
source /data/qwen35_env/bin/activate
cd /data/ai_infra/17_多模态生成Infra

python 17.1_生成模型推理基础/dit_cost_estimator.py      # 成本杠杆定量：分辨率/步数/CFG
python 17.3_视频生成系统与并行/parallel_dit_sim.py      # 并行加速比：CFG并行 vs USP
```

## 阅读建议

1. 先读 17.1 建立"生成推理 vs LLM 推理"的对比认知，这是全章的地基。
2. 两个脚本必跑：成本结构（17.1）和并行收益（17.3）是面试手算题的直接素材。
3. 与 5.12（ring attention）、6.5（PP）、7 章（量化）交叉读，体会技术迁移。
4. 目标岗位含视频/图像生成方向（短视频/电商/游戏/自动驾驶仿真）时，本章是必备补丁；纯 LLM 方向可选读 17.1 + 17.4 建立认知即可。
